# 📁 Guía de imágenes — JR Seguros

Este documento explica cómo organizar las imágenes de la página web.

## Estructura de carpetas

```
img/
├── hero/       → Banner principal (sección de bienvenida)
├── logo/       → Logotipos de JR Seguros
├── about/      → Imágenes de la sección "Sobre nosotros"
├── seguros/    → Imágenes de los tipos de seguro (vida, hogar, vehículo, etc.)
├── contacto/   → Imágenes de la sección de contacto
├── carrusel/   → Imágenes para carrusel o slider
├── novedades/  → Imágenes de promociones, noticias o novedades
└── footer/     → Imágenes del pie de página
```

## Cómo agregar una imagen

1. Coloca la imagen en la carpeta que corresponda según la sección donde quieras que aparezca.
2. Dale un nombre descriptivo sin espacios ni caracteres especiales. Ejemplo: `seguro-vida.jpg`
3. Avísale al desarrollador la ruta y la ubicación exacta donde debe ir.

## Recomendaciones

- Usa formato **.jpg** o **.webp** para fotos (pesan menos).
- Usa **.png** para logotipos o imágenes con fondo transparente.
- Procura que las imágenes no pesen más de **300 KB** para que la página cargue rápido.
- Las imágenes del banner (`hero/`) deben tener al menos **800 px de ancho**.
